# Chrome ウェブストア掲載情報（日本語）

各セクションを Chrome ウェブストア デベロッパー ダッシュボードの対応する欄に貼り付けます。

## 名前

Urzk Tab Manager

## 短い説明

<!-- 65 characters (limit 132) -->

新しいタブで、すべてのウィンドウのタブを一覧・整理できます。タイトル、サイト、読み込み状態で検索。1000 タブ以上でも快適です。

## 詳しい説明

Urzk Tab Manager は、新しいタブのページを、すべての Chrome ウィンドウで開いているタブの一覧に置き換えます。混み合ったタブバーを探し回らなくても、タブを見つけて、整理して、閉じられます。

主な機能

• すべてのウィンドウをひと目で。現在のウィンドウを先頭に展開して表示し、ほかのウィンドウは開閉できます。ウィンドウごとにタブ数を表示し、最小化・フォーカス・閉じるボタンがあります。
• タブカード。各タブのファビコン、タイトル、URL を表示します。カードをクリックするか Enter キーを押すと、そのタブに切り替わります。破棄（メモリから解放）されたタブは薄く表示されます。
• クイック操作。カードにマウスを乗せるか、キーボードでフォーカスすると、タブの破棄、閉じる、新しいウィンドウへの切り出し、現在のウィンドウの末尾への移動、上下左右への移動ができます。フォーカス中のタブは矢印キーでも移動できます。
• 検索。入力した単語をこの順にタイトルに含むタブを探します（大文字と小文字は区別しません）。site:example.com でそのサイトとサブドメインのタブに、loaded:（または l:）で読み込み済みのタブに絞り込めます。検索中、一致するタブがないウィンドウは表示されません。
• ツールバーボタンとショートカット。ツールバーボタンをクリックするか Alt+Shift+T を押すと、タブマネージャーを開きます。すでに開いている場合は、新しく開かずにそのタブに切り替えます。ショートカットは chrome://extensions/shortcuts で変更できます。
• 大量のタブに対応。タブのイベントで Chrome と同期し、定期的に Chrome の状態と照合するので、1000 タブを超えても一覧が正確に保たれます。
• 英語と日本語に対応（ブラウザの言語設定に従います）。

プライバシー

Urzk Tab Manager は、データを一切収集・保存・送信しません。タブのタイトルと URL は一覧の表示のためだけに読み取り、お使いのコンピューターのメモリ上でのみ扱います。アクセス解析、アカウント、リモートコードはありません。

# プライバシーへの取り組み タブ

## 単一用途

Urzk Tab Manager の用途は一つです。新しいタブのページに、すべてのウィンドウで開いているタブを一覧表示し、ユーザーがタブを探す、切り替える、移動する、破棄する、閉じることを可能にします。

## 権限が必要な理由

### tabs

開いているタブのタイトルと URL を読み取り、新しいタブのページで一覧表示・管理するために使います。各タブのタイトルと URL の表示、タブの検索、およびユーザーの操作によるタブの切り替え・移動・破棄・閉じるに使います。

### favicon

ページ自身のアイコンを取得できないときに、Chrome がキャッシュしているファビコンを表示するために使います。

### ホスト権限

要求しません。

### リモートコード

いいえ、リモートコードは使用していません。JavaScript はすべて拡張機能に同梱しており、コンテンツ セキュリティ ポリシーで拡張機能自身のスクリプトのみを許可しています。

## データの使用

この拡張機能は、ユーザーデータを収集・送信しません。

いずれの種類のデータも収集しません（個人を特定できる情報、健康に関する情報、財務情報と支払い情報、認証情報、個人的な通信、位置情報、ウェブ履歴、ユーザーのアクティビティ、ウェブサイトのコンテンツ）。タブのタイトルと URL は、タブ一覧を表示するためにユーザーの端末のメモリ上でのみ処理し、保存も送信もしません。
